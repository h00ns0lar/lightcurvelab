# 시계열 측광 분석 프로그램 실행 가이드

`시계열분석프로그램1_로컬.py` — 별의 밝기 변화를 시간에 따라 분석하는 프로그램을 **본인 컴퓨터에서** 실행하는 방법입니다. 인터넷 사이트(Colab 등)에 접속할 필요 없이, 컴퓨터에 있는 사진 파일을 그대로 사용합니다.

---

## 1. 준비물 확인

### 1-1. Python이 설치되어 있는지 확인

`cmd`(명령 프롬프트)를 열고 아래 명령어를 입력합니다.

```bash
python --version
```

`Python 3.x.x` 같은 버전이 나오면 설치되어 있는 것입니다. 만약 "python은 내부 또는 외부 명령이 아닙니다" 같은 오류가 나오면, [python.org](https://www.python.org/downloads/)에서 설치부터 해야 합니다. (설치 시 "Add Python to PATH" 체크박스를 꼭 체크하세요.)

### 1-2. 필요한 라이브러리 설치

같은 `cmd` 창에서 아래 명령어를 한 번 실행합니다. (이미 설치되어 있는 항목은 건너뛰고, 없는 것만 자동으로 설치됩니다.)

```bash
pip install astropy photutils numpy pandas matplotlib
```

몇 분 정도 걸릴 수 있습니다. "Successfully installed..." 메시지가 나오면 완료입니다. **이 설치는 한 번만 하면 됩니다** — 다음부터는 이 과정을 반복할 필요가 없습니다.

---

## 2. 데이터 준비

### 2-1. FITS 파일 구조

이 프로그램은 **같은 별을 여러 번(시간 간격을 두고), 여러 필터(예: g, r, i)로 반복 촬영한 FITS 파일들**이 필요합니다. 필터당 1장씩만 있으면 안 되고, 시간에 따라 여러 장 찍은 것이어야 광도곡선이 나옵니다.

### 2-2. 전처리(Bias/Dark/Flat 보정)

이 프로그램은 **측광만 하고 전처리는 하지 않습니다.** MaxIm DL, Siril, PixInsight 같은 프로그램으로 미리 Bias/Dark/Flat 보정을 끝낸 파일을 준비해두세요.

### 2-3. 폴더/파일명 구조

전처리 후 파일들이 한 폴더에 필터 구분 없이 섞여 있어도 괜찮습니다. **파일명 끝이 `-g.fit`, `-r.fit`, `-i.fit` 처럼 필터로 구분되어 있으면 됩니다** (지금 이 프로그램은 실제로 이 구조로 되어 있는 YZ Bootis 데이터를 기준으로 만들어졌습니다).

---

## 3. 프로그램 설정

`시계열분석프로그램1_로컬.py` 파일을 메모장(또는 VS Code)으로 열고, 파일 위쪽 **`[설정]`** 구역의 값들을 확인/수정합니다.

| 변수 | 의미 | 예시 |
|---|---|---|
| `BASE_DIR` | FITS 파일들이 들어있는 폴더 경로 | `C:\26astro\YZBootis\result\pp` |
| `FILE_PATTERN_BY_FILTER` | 필터별 파일명 패턴 | `{'g': '*-g.fit', 'r': '*-r.fit', 'i': '*-i.fit'}` |
| `OUTPUT_DIR` | 결과(CSV, 그래프)를 저장할 폴더 | `C:\26astro\YZBootis\result` |
| `GAIN_DEFAULT` | 카메라 이득값(자동 재측정됨, 몰라도 됨) | `0.71` |
| `TARGET_ID`, `COMP_IDS` | 대상 별/비교성 번호 (처음엔 모르므로 `None`으로 둠) | `TARGET_ID = 0` |

처음 실행할 때는 `TARGET_ID = None`, `COMP_IDS = None`으로 그대로 두면 됩니다.

---

## 4. 실행 방법

### 4-1. 1차 실행 (별 번호 확인용)

```bash
cd "저장소를 받은 폴더\python"
python "시계열분석프로그램1_로컬.py"
```

실행하면:
- 화면에 탐지된 별 목록(번호, 좌표, 밝기)이 출력됩니다.
- `OUTPUT_DIR` 폴더에 **`preview_stars.png`** 파일이 생성됩니다.
- `TARGET_ID`/`COMP_IDS`가 비어있으므로 여기서 멈춥니다.

### 4-2. 별 번호 확인

`preview_stars.png`를 열어봅니다 (사진 뷰어로 더블클릭). 빨간 원과 노란 숫자가 탐지된 별들입니다.

- **대상 별**: 보통 화면 중앙 근처에 있고 밝은 별입니다 (관측할 때 망원경을 그 별에 맞춰 추적하기 때문).
- **비교성**: 대상과 밝기가 비슷하고, 다른 별과 겹치지 않은 고립된 별을 2개 이상 고릅니다.

### 4-3. 설정값 입력 후 재실행

`시계열분석프로그램1_로컬.py`를 다시 열어서:

```python
TARGET_ID = 0          # 확인한 대상 별 번호로 수정
COMP_IDS = [1, 2, 3]   # 확인한 비교성 번호들로 수정
```

저장한 뒤 다시 실행합니다.

```bash
python "시계열분석프로그램1_로컬.py"
```

이번에는 전체 분석(비교성 안정성 검증 → 조리개 최적화 → 필터별 측광 → 아웃라이어 제거 → 결과 저장)이 순서대로 진행됩니다.

## 5. 결과 확인

`OUTPUT_DIR`로 지정한 폴더에 아래 파일들이 생성됩니다.

| 파일명 | 내용 |
|---|---|
| `photometry_results.csv` | 프레임별 측광 결과 표 (시간, 등급, 오차 등) |
| `preview_stars.png` | 별 탐지 미리보기 |
| `aperture_optimization.png` | 조리개 반지름 최적화 그래프 |
| `lightcurve_by_filter.png` | 필터별 광도곡선 |
| `lightcurve_combined.png` | 모든 필터를 합친 광도곡선 |
| `color_index.png` | 색지수(예: g-r) 시간 변화 그래프 |

`photometry_results.csv`는 엑셀로 열어서 직접 확인/편집할 수 있습니다.

## 6. 자주 발생하는 문제

- **`ModuleNotFoundError: No module named '...'`**: 1-2단계의 `pip install` 명령어를 다시 실행하세요.
- **`FileNotFoundError: '...' 에서 '...' 패턴의 파일을 찾지 못했습니다`**: `BASE_DIR` 경로나 `FILE_PATTERN_BY_FILTER`가 실제 폴더/파일명과 맞는지 확인하세요.
- **별이 하나도 탐지되지 않음**: 파일 안의 `DETECT_THRESHOLD_SIGMA` 값을 낮춰보세요 (기본 8.0 → 5.0 등).
- **그래프에 이상한 튀는 점이 많음**: `MAX_CENTROID_SHIFT_PX`, `MAX_DIFF_MAG_ERR_MULTIPLIER` 값을 설정 구역에서 조정해서 다시 실행하세요.
