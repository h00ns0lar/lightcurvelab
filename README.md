# FITS 광도곡선 실험실

망원경으로 같은 별을 여러 장 찍은 FITS 사진에서 **별의 밝기 변화(광도곡선)** 를 직접 구해 보는 교육용 도구입니다.
외계행성 식현상(트랜짓)과 변광성 관측 자료를 분석하려고 학술제 프로젝트로 만들었습니다.

**사이트에서 바로 써 보기:** `https://<GitHub아이디>.github.io/<저장소이름>/`

## 무엇을 하나요

브라우저 한 페이지 안에서 Colab 노트북처럼 단계를 하나씩 진행합니다. 사진은 서버로 올라가지 않고, 모든 계산이 내 컴퓨터의 브라우저 안에서 이루어집니다.

1. **사진 불러오기**: `.fit` 파일 여러 장이나 폴더를 고릅니다. 사진이 없으면 예제 데이터로 해 볼 수 있습니다.
2. **별 찾기**: 첫 사진에서 별을 자동으로 찾습니다.
3. **대상별과 비교성 고르기**: 사진을 클릭하거나 좌표를 넣어 고릅니다.
4. **정렬과 측광**: 시야 회전과 흔들림을 보정하고, 반지름을 여러 개로 바꿔 가며 구경측광을 합니다.
5. **비교성 검사와 반지름 추천**: 밝기가 흔들리는 비교성을 걸러 내고 잡음이 가장 작은 반지름을 고릅니다.
6. **광도곡선**: 시간 묶음, 튀는 값 제거, 추세 제거를 하고 상대 플럭스나 등급으로 그립니다.
7. **식 피팅**: 주연감광을 고려한 트랜짓 모델로 식 깊이, Rp/R★, 신호대잡음비를 구합니다. HAT-P-1b 궤도 정보가 미리 들어 있습니다.
8. **결과 정리**: 표준편차와 오차를 표로 보여 주고, 프레임별·10분 묶음·요약 CSV를 내려받습니다.

## 오프라인으로 쓰기

`index.html`을 내려받아 더블클릭하면 인터넷 없이도 열립니다. 글꼴만 인터넷에서 받아 오고, 인터넷이 없으면 기본 글꼴로 보입니다.
Chrome이나 Edge 최신 버전을 권장합니다.

## 분석 예시: HAT-P-1b (2026-09-19, R필터, 349장)

| 항목 | 측정값 | NASA Exoplanet Archive |
|---|---|---|
| 식 깊이 | 1.43 ± 0.13 % | 1.39 % ((Rp/R★)²) |
| 지속 시간 | 2.78 ± 0.16 h | 2.85 h |
| 식 밖 표준편차 | 0.46 % (10분 묶음 0.20 %) | — |

문헌값은 [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/overview/HAT-P-1%20b) 기본값(Nikolov et al. 2014)입니다.

## 계산 방법 요약

- **측광**: 원형 구경 안의 빛을 서브픽셀(5×5) 가중치로 더하고, 배경 고리에서 시그마 클리핑으로 하늘 밝기를 뺍니다.
- **차등측광**: 대상별 등급에서 비교성들을 역분산 가중 평균한 등급을 뺍니다.
- **시각**: 노출 중간 시각을 BJD_TDB로 바꿉니다.
- **식 모델**: 2차 주연감광 법칙을 수치 적분하고, 상수·대기질량 추세·식 깊이를 최소제곱으로 함께 맞춥니다.
